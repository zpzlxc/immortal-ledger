# 长生簿

一款纯网页、单人、文字驱动的轻度放置修仙游戏。

你会在有限寿元里，从一个刚刚踏入修行的凡人开始，安排每一次吐纳、探索和选择。你离开网页之后，角色仍会继续行动；再次回来时，长生簿会把这段时间发生的事情一一记下。

## 世界观

修仙并不是一条铺满奇遇的直路。

天地间确实存在灵气、功法和宗门，但更多时候，修行只是一个人在山风、旧卷和漫长岁月里，反复确认自己要成为什么样的人。每一次行动都会消耗时间，每一次选择都会留下因果；灵石和修为可以积累，寿元却只能向前流逝。

你所拥有的，是一本来历不明的长生簿。它会记录你的名字、境界、遇见的人、走过的地方，以及那些没有被任何人看见的决定。有人说，长生簿只是记录人生的法器；也有人相信，它正在等待某一世的你，写出被前人遗漏的最后一页。

故事从三处地方展开：

- **青石山**：低风险的起点。旧猎道、山狐和红线铜铃，藏着凡人生活与修行世界交界处的细小痕迹。
- **黑风谷**：风声常年不散的险地。断碑、阵眼和无灯人的身影，会把你引向残缺的功法与更难解释的旧事。
- **无名古井**：没有井水，只有迟到的回声。井壁上的倒名、空灯和无名残魂，可能与你自己的来处有关。

你也会遇见三类重要的人：愿意给秘密标价的行脚商人林秋、在山门外观察你的玄松道人，以及没有名字、却比你更早知道你心事的无名残魂。与他们的关系不会只增加一个数值，某些选择会改变后续事件、资源、属性与因果。

## 玩法概览

游戏的核心循环是：

```text
创建角色
  ↓
查看长生簿，处理离线期间的结果
  ↓
处理待选的人物或探索事件
  ↓
安排一项行动
  ↓
关闭网页，让角色继续生活
  ↓
回来领取结果，继续选择
```

一次只安排一项行动。行动会按照真实时间倒计时，页面关闭后也会继续结算；单次离线结算最多计算 8 小时，避免一次离开太久造成失控的收益。

### 1. 修炼与突破

你可以根据当前状态选择不同功课：

| 行动 | 主要作用 | 代价或风险 |
| --- | --- | --- |
| 平稳吐纳 | 稳定获得修为 | 风险极低，成长最可靠 |
| 淬体炼骨 | 提升根骨并获得修为 | 有灵草时效果更好，无药时收益较低 |
| 静观参悟 | 提升悟性、神识与心境 | 修为收益较少，但有助于长期成长 |
| 极限运功 | 在短时间内获得更多修为 | 消耗心境，并可能损伤根骨 |
| 突破 | 尝试跨过当前境界瓶颈 | 成功率受心境与悟性影响，失败会损失心境 |

当前可见的境界包括炼气与筑基。境界之外，根骨、悟性、神识、心境、气运和因果也会影响你的选择与结果。

### 2. 功法与流派

你可以选择一条修行方向，并逐步研究对应的入门功法：

- **剑修 / 逐风剑诀**：偏向探索和危险之地的收益。
- **丹修 / 百草丹经**：更擅长研读残卷、获取功法残页。
- **阵修 / 聚星阵解**：让吐纳更加稳定，并与洞府的聚灵阵产生联系。
- **魂修 / 守一观想法**：更快推进功法熟练度，深入识海与回声的秘密。

每门功法都有入门、进阶和高阶三个研究分支。研读残卷获得熟练度与功法残页，再决定要把有限的资源投入哪一条分支；不同分支会实际影响修炼、探索或研究收益。

### 3. 探索与事件

探索地点会逐步解锁：完成青石山探索后开放黑风谷，完成黑风谷探索后开放无名古井。不同地点有独立的耗时、风险、奖励和事件池。

探索完成后，不一定只是自动领取资源。有机会触发需要主动处理的事件，例如：

- 取下树梢的红线铜铃，还是只带走纸条；
- 按阵纹修复黑风谷的断碑，还是直接劈开取宝；
- 触碰无名古井的倒名，还是抹去最后一笔。

这些选择会改变灵石、灵草、功法残页、修为、属性和因果，并可能影响人物关系与后续事件。事件只在本世的特定条件下推进，长生簿会保留已经发生过的决定。

### 4. 洞府与资源

第一次探索后，你会在山中找到一处可以安身的石窟，逐步把它建成自己的洞府：

- **聚灵阵**：离线积攒修为，提高部分修炼收益。
- **灵田**：离线产出灵草。
- **藏经阁**：减少研读残卷所需的时间。

建筑最多升级到三级。升级需要消耗灵石和灵草，洞府产出会在你回来时统一结算，也可以手动收取。

### 5. 人物与宗门

与人物交互会提升或降低好感，并在陌生、熟悉、信任、敌对之间变化。林秋、玄松道人和无名残魂各自拥有多阶段事件，是否帮助、交易、追问或保持距离，都会影响这条关系线的走向。

获得玄松道人的引荐后，可以加入一座宗门：

- **青霄剑宗**：偏向修炼与探索。
- **百草谷**：偏向灵草、研读与功法成长。
- **天机阁**：偏向阵法、悟性和研究效率。

入门后可以安排宗门任务，获得声望与贡献。声望会对应外门弟子、记名弟子、内门弟子和门中执事等阶段，也可以兑换灵石、灵草或功法残页。

### 6. 寿元与轮回

每个角色都有有限寿元。行动会推进年龄，寿元耗尽后，本世结束，并生成一份本世总结：你的境界、走过的地点、遇见的人、加入的宗门和关键事件，都会留在长生簿中。

下一世可以重新选择名字与天赋。前世不会把大量修为直接带回来，但会留下少量遗泽，例如已发现的地点、最多三页功法残页和前世名字。轮回的意义不是跳过成长，而是让每一世都能在前人的痕迹上走得稍微不同。

## 适合怎样游玩

《长生簿》不是需要持续盯着屏幕的即时战斗游戏，也没有要求你每天完成任务的体力系统。比较合适的节奏是：

1. 打开游戏，先读长生簿中刚刚结算的记录。
2. 处理眼前的人物或探索事件。
3. 根据心境、资源、寿元和当前目标安排下一项行动。
4. 关闭页面，过一段时间再回来。

你可以走稳妥的散修路线，也可以为了功法残页深入险地；可以专注突破境界，也可以把一世时间花在某个人、某座宗门或那口没有水的古井上。游戏没有唯一正确答案，重要的是这一世最后留下了什么。

## 当前已实现

- 角色创建、先天天赋选择与基础属性。
- 炼气境界、修为积累、突破成功/失败和筑基入口。
- 四种修炼行动、三处探索地点和地点解锁链。
- 探索事件选择与多阶段人物事件。
- 四条功法流派、四门入门功法、熟练度与三段研究分支。
- 洞府解锁、聚灵阵/灵田/藏经阁和三级建筑升级。
- 林秋、玄松道人、无名残魂三条关系线。
- 青霄剑宗、百草谷、天机阁、宗门任务、声望等级与声望兑换。
- 行动倒计时、页面刷新后的结算和最多 8 小时离线结算。
- 长生簿日志、未读标记、寿元耗尽、本世总结与基础轮回继承。
- 浏览器本地存档、JSON 存档导入与导出。

当前仍是 MVP，重伤与治疗、更多境界内容、宗门专属主线、多门功法并修、云端存档和多人功能尚未实现。

## 本地运行

需要 Node.js 环境：

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。生产构建：

```bash
npm run build
```
