# 长生簿

纯网页、单人、文字版修仙游戏。当前是可玩的 MVP 原型，核心循环为：

```text
创建角色 → 查看长生簿 → 安排行动 → 离线等待 → 回来领取结果
```

## 本地运行

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。生产构建：

```bash
npm run build
```

## 当前已实现

- 角色创建和先天天赋选择
- 炼气境界、修为与基础属性
- 平稳吐纳、淬体炼骨、静观参悟、极限运功、青石山探索、研读残卷
- 行动倒计时与最多 8 小时离线结算
- 长生簿日志时间线
- 基础突破逻辑，炼气圆满可进入筑基
- 浏览器本地存档、导入和导出
- 洞府 MVP：首次探索解锁、聚灵阵/灵田/藏经阁、三级建造升级、离线产出和收取
- 三处探索地点：青石山、黑风谷、无名古井，带地点选择、解锁链、独立耗时、风险和奖励
- 四种功法流派、四门入门功法、熟练度成长和三段研究分支；分支效果会影响修炼、探索或研读
- 人物与宗门 MVP：林秋、玄松道人、无名残魂三条关系线，人物事件选项，三座可加入宗门和宗门贡献
- 宗门任务：每座宗门两项差事，支持任务倒计时、资源奖励、声望、贡献和外门/记名/内门/执事等级
- 多阶段人物事件：林秋、玄松道人、无名残魂在高好感和后续行动后会继续展开新的事件
- 宗门声望兑换：可将声望兑换为灵石、灵草或功法残页
- 旧版存档自动迁移到洞府与功法数据结构
- 修炼与图鉴页面

当前开发进度见 [`docs/development-progress.md`](docs/development-progress.md)；详细产品与开发规划见 [`docs/game-development-guide.md`](docs/game-development-guide.md)。
